


# Little Bytey

Little Bytey cosplay pet from *The Finals* that can move and change faces.

![Little Bytey](img/render.png)

## (BOM)

- 1x 1.54" IPS LCD, 240×240, ST7789, SPI
- 1x ESP32-C3 SuperMini
- 1x SG90 9g micro servo
- 1x TTP223 capacitive touch module
- 1x Electrolytic capacitor, 470–1000 µF, 6.3–10V
- 8x Neodymium disc magnets, 6×3 mm, N52
- 1x Copper foil tape, 25 mm wide, conductive adhesive
- Miscellaneous wires and heat-shrink tubing
